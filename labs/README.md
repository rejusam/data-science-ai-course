# Labs

Lab exercises, released as the course reaches them.

Labs are attempted before the review session, not after. The point is to
struggle with the problem first. Watching a solution to a problem you have not
tried feels productive and teaches very little.

Each lab folder contains the notebook, any data it needs, and a README stating
what you should be able to do by the end of it.

## Working on a lab

```
conda activate dsai
jupyter lab
```

Start Jupyter from the repository root so that relative paths to `data/`
folders resolve as written.

## If you get stuck

Spend a while stuck first. That is where the learning happens.

After that, in order: re-read the error message from the bottom up, check the
library documentation, ask in Slack, bring it to the 30 minute support session
before class.

Post the actual error text rather than a screenshot where you can. Text is
searchable, and someone else in the cohort has probably hit the same thing.
