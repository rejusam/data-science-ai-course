- Probability, sampling, hypothesis testing, p-values, confidence intervals

## Labs and activities

## How to get the most out of these sessions

- Do the maths by hand once before doing it in NumPy
- Sketch the gradient-descent path on paper - visual intuition beats memorising formulas
- Recreate each chart with a different dataset
- Explain a p-value out loud in one sentence to a classmate - teaching is the fastest test of understanding
