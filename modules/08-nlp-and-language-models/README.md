## How to get the most out of these sessions

- Build a regex cheat sheet you keep for life
- Respect robots.txt and rate limits - ethics questions come up in interviews
- Run the pipeline over text from your own domain
- Inspect the misclassified examples - that is where the learning is
- Treat the LLM as a collaborator you must fact-check, never as an authority
